# Design notes

One short note per modeling or architecture decision, numbered in order (`0001-ownership-as-role-nodes.md`, …). They become the ontology's design rationale in the capstone.

## Template

```markdown
# NNNN: Title

Date: YYYY-MM-DD

## Decision
What we chose, in one or two sentences.

## Context
The competency questions or data problems that forced the choice.

## Alternatives considered
What else we could have done, and why not.

## Consequences
What this makes easy, what it makes hard, and what to revisit.
```
